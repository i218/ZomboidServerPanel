# ServerPanelBridge

Отдельный мод для Project Zomboid Build 42: передаёт состояние dedicated server в ServerPanel через ZombieBuddy.

[English version](README.md)

## Что показывает панель

Сервер появляется в категории **Game servers**. Каждые пять секунд обновляются:

| Показатель | Значение |
| --- | --- |
| Online | Панель недавно получила heartbeat |
| Health | Healthy, пока идут игровые тики; Degraded после 20 секунд без тиков |
| CPU | Нагрузка процесса JVM с нормализацией по логическим процессорам |
| Memory | Используемая Java heap в МиБ, не вся память процесса |
| Uptime | Время работы JVM |

Online и Degraded могут отображаться одновременно: фоновый отправитель работает, но игровые тики остановились. После завершения процесса или потери связи панель помечает сервер как offline.

Отправка работает в фоне. Недоступная панель не задерживает игровой поток. Таймаут запроса — две секунды, задержка повторов увеличивается до 30 секунд. Связь восстанавливается автоматически.

Этот выпуск реализует **мониторинг**. Команды запуска, остановки и перезапуска пока не исполняются. Для игроков и обновлений Workshop в API панели ещё нет отдельных полей.

## Один установщик

1. Закрой игру и dedicated server.
2. Запусти **ServerPanelBridge-Setup.exe**. Админка обычно не нужна.
3. Укажи фактическую папку данных Zomboid (cachedir) серверного пользователя и выбери существующий сервер.
4. Оставь включённой настройку dedicated server. Если составляешь серверный INI через клиент, можно отметить включение в клиентском списке модов.
5. Нажми «Установить», затем запусти сервер и ServerPanel на той же машине.

В EXE уже встроены мод и собранный JAR. Установщик распакует файлы, добавит ZombieBuddy и ServerPanelBridge в выбранный INI, создаст отсутствующий runtime-конфиг и проверит записанные файлы. Существующий конфиг и остальные настройки сохраняются. Резервные копии — в `<cachedir>/ServerPanelBridge-installer-backups/`. При ошибке записи выполняется откат.

ZombieBuddy Java agent должен быть установлен заранее; ServerPanel устанавливается отдельно. Установщик не запускает и не останавливает приложения, не меняет WorkshopItems и не обходит доверие ZombieBuddy. JAR остаётся неподписанным.

По умолчанию установка только серверная. Клиентская галочка необязательна: она включает этот же локальный мод в `mods/default.txt`, чтобы удобнее было составлять настройки через игру.

**Подключающимся игрокам ServerPanelBridge не нужен.** После загрузки адаптер удаляет только его запись из списка обязательных клиентских модов Build 42; серверный код и остальные моды сохраняются. Если API несовместим, в логе будет ошибка. Реальное подключение без мода ещё нужно проверить на сервере. Требования самого ZombieBuddy к клиентам остаются прежними.

Для автоматической установки:

```powershell
.\ServerPanelBridge-Setup.exe --silent --data-dir "D:/PZData" --server-name "servertest" --mode server
```

Режимы: `server` (по умолчанию), `client`, `both`. Успех — код 0, ошибка — код 1 и диагностический файл в Windows Temp. Для пути используй фактическую папку, не junction/symlink.

Ручная альтернатива: распаковать **ServerPanelBridge-mod.zip** в `<cachedir>/mods/` и добавить мод после ZombieBuddy в `Mods=`. Предмет Steam Workshop пока не опубликован.

## Настройки

После первого серверного тика мод создаёт:

```text
<Zomboid cachedir>/ServerPanelBridge/<имя сервера>/ServerPanelBridge.properties
<Zomboid cachedir>/ServerPanelBridge/<имя сервера>/ServerPanelBridge-0.log
```

Путь cachedir берётся из игры, включая пользовательский `-cachedir`. Логи занимают до трёх файлов по 1 МиБ. Меняй настройки при остановленном сервере и затем перезапускай его.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| enabled | true | false отключает отправку |
| panelUrl | http://127.0.0.1:5088 | Только локальная панель на той же машине |
| hostId | pz-<имя сервера> | Уникальный постоянный идентификатор |
| hostName | Project Zomboid: <имя сервера> | Имя в панели |
| category | Game servers | Категория |
| environment | Production | Подпись среды |
| address | Local dedicated server | Подпись, не адрес подключения |
| heartbeatSeconds | 5 | Интервал 5–10 секунд |
| requestTimeoutSeconds | 2 | Таймаут 1–5 секунд |
| staleTickSeconds | 20 | Когда считать игровые тики устаревшими |
| maxRetrySeconds | 30 | Максимальная задержка повтора |

[Пример конфига](config/ServerPanelBridge.properties) в архиве — справочная копия. Активный конфиг создаётся автоматически в cachedir.

Мод не собирает имена игроков, Steam ID, IP, пароли или содержимое серверного INI.

## Проверка после установки

1. Дождись появления сервера в панели.
2. Проверь изменение CPU, памяти и uptime.
3. Закрой ServerPanel, оставив сервер работать. В логе появится предупреждение о связи, игра продолжит работу.
4. Снова запусти панель. Heartbeat возобновится автоматически.
5. Штатно останови dedicated server. После истечения окна свежести heartbeat панель покажет offline — сейчас это 15 секунд.

Для проверки не нужно принудительно завершать процесс. Чтобы отключить отправку, поставь `enabled=false` и перезапусти сервер.

## Сборка

Нужны JDK 11 или новее и Gradle 8.7:

```powershell
.\gradlew.bat --no-daemon clean build installer
```

Единый установщик: `build/distributions/ServerPanelBridge-Setup.exe`.

Архив с готовым JAR: `build/distributions/ServerPanelBridge-mod.zip`.

Подробности проверок — [VERIFICATION.md](VERIFICATION.md). Подтверждение загрузки на живом сервере остаётся отдельным шагом: сборка не доказывает, что ZombieBuddy доверился неподписанному JAR.
